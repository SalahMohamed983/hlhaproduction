# هلها ميديا — React + Tailwind (JavaScript)

نسخة مبسّطة من موقع هلها ميديا باستخدام **React** و **Tailwind CSS** و **JavaScript** (بدون TypeScript).

## التشغيل

```bash
cd hala-media-react-js
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
npm run preview
```

## المميزات

- نفس تصميم الموقع الأصلي (أقسام، splash، modals)
- **الوضع الليلي** من زر القمر/الشمس في الهيدر (يُحفظ في `localStorage`)
- كود منظم في مجلدات: `components`، `context`، `data`، `hooks`
